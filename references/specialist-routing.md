# 单入口专家路由

## 入口规则

用户默认只调用 `$lvsea-writing`。它先识别任务，再按需调用专用 Skill；不要因为任务同时出现“素材”“写作”或“AI 味”就把三个 Skill 全部加载。

专用 Skill 可以被用户显式调用，但它们不是平级的通用入口：

| 用户意图 | 路由 | 交接边界 |
| --- | --- | --- |
| 小红书素材库、关键词、互动指标、评论区、飞书整理 | `$lvsea-xiezuo` | 输出证据卡、二创简报或写作接力包，不负责通用长文和终稿去 AI 味 |
| 普通写作、改稿、研究型长文、制造管理、政策、教程、PPT、口播 | `lvsea-writing` 内部主流程 | 从任务契约走到初稿和场景审校 |
| 已有完整成稿，只要求最后去 AI 味 | `$lieflat-less-ai-tone` 或本 Skill 的严格后处理模式 | 只做白名单命中、最小修改和信息守恒复查 |
| 从小红书素材写成完整文章并完成终稿 | `$lvsea-xiezuo -> lvsea-writing -> lieflat-less-ai-tone` | 每阶段必须通过交接门，不能跳过证据和结构 |

`lvsea-writing` 是主入口，`lvsea-xiezuo` 是素材专家，`lieflat-less-ai-tone` 是终稿后处理器。三者的职责不互换。

## 路由判定

1. 先判断用户要的是素材研究、写作过程、已有成稿清理，还是组合任务。
2. 只要任务包含小红书素材采集、互动门禁、评论分析或飞书素材库，就先走 `$lvsea-xiezuo`；它生成的接力包再进入 `lvsea-writing`。
3. 只要任务需要从材料形成观点、结构或正文，就走 `lvsea-writing` 主流程；不要直接把材料丢给 Humanizer。
4. 只有完整草稿、事实和结构已经稳定时，才进入 `$lieflat-less-ai-tone` 或严格后处理模式。
5. 只要求检测不改时，输出检测报告并停住；不要自动进入下一阶段。

## 专家不可用时的降级

- `$lvsea-xiezuo` 不可用：接受用户自有 JSON/CSV 或现有资料，保留来源、观察、推断和待核项；不声称已经完成小红书平台采集。
- `$lieflat-less-ai-tone` 不可用：使用 [最后编辑适配说明](late-humanizer-adapter.md) 的严格白名单模式；不退回到“温暖、口语、加故事”的泛化润色。
- 两个专家都可用时，也只读取当前阶段需要的内容，避免上下文膨胀。

## 交接物

素材专家交给主入口：`source_basis`、`observed`、`inference`、`open_question`、`ownership`、`new_angle` 和 `prohibited_directions`。

主入口交给终稿后处理器：完整草稿、体裁/场景、作者声音约束、事实边界和需要保留的格式。终稿后处理器返回命中规则、最小修改和未修改理由；最终是否署名仍由作者决定。
