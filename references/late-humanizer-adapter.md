# 最后编辑适配说明

## 来源与定位

终稿后处理优先参考 [larashero3-dotcom/lieflat-less-ai-tone](https://github.com/larashero3-dotcom/lieflat-less-ai-tone)，固定复核版本为 `27d29232f10124db904ca9c0536d0b67cb3b2833`，许可证为 MIT。它是一个成稿后的窄编辑器，不是研究、结构、风格建模或作者终审 Skill。

它报告了 11 类可定位信号，但同时排除了“句长不够参差”“正文问句”“比喻本身”“被动句”等不能稳定作为删改理由的特征。统计结果只用于确定复查范围，不用于证明作者身份或保证平台检测结果。

## 严格后处理合同

进入本阶段前必须满足：

- 草稿已经完成事实、主线、读者、场景和技术/格式检查；
- 任务不是“先检测不改”；
- 作者没有要求保留某个特定表达时，才允许做最小编辑；
- 原文的标题层级、段落顺序、列表、表格、引用、代码块和链接默认不动。

执行时只做：

1. 按上游明确列出的触发标记逐处检查，不建立新的禁词表。
2. 只改解决命中问题所必需的文字，不顺手润色邻句。
3. 保留姓名、数字、日期、引语、来源、因果、限定词和判断强度；不新增经历、场景、心理、数据或结论。
4. 把“未命中规则”的句子视为保留项，不为了追求节奏或口语感重写。
5. 输出 `humanizer-review.md` 时记录命中的规则、修改位置、信息守恒检查和仍需作者判断的项目。
6. 反查一次：如果改动无法指出对应规则，撤销改动；最后交给作者终审。

## 禁止提前使用

不能对题目、资料摘录、证据账本、提纲或未完成初稿运行本模式。不能把“去 AI 味”当成补事实、补案例、补人称、补口头禅或重组观点的理由。

当 `$lieflat-less-ai-tone` 已安装时，优先按其原始 Skill 执行；未安装时，`lvsea-writing` 只使用本合同和自身的中文语境检查作为降级路径，不复制或声称完整复现上游规则。
