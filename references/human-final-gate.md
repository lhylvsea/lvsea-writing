# 作者人工终审

## 目的

最后一关不是再套一层“更像人”的提示词，而是让真正对内容负责的人做取舍。模型可以检查残留模式、朗读阻力和事实账本，但不能凭空获得作者的经历、判断位置、责任边界和署名意愿。

## 终审顺序

1. **事实回看**：逐项核对数字、日期、名称、引语、链接、产品能力、政策范围、人物动作和来源归属。无法确认的保留待核验，不要用更顺的句子盖过去。
2. **作者位置**：问“这是我真正知道、相信或愿意承担的判断吗？”不是作者亲自经历的内容，不用第一人称和现场口吻冒充。
3. **读出声**：读完整篇，标出需要憋气、突然变正式、连续同节拍、解释已经被动作说明的句子。只改影响理解或确实不像作者的地方。
4. **具体取舍**：删掉低信息句、无来源的漂亮话和强行升华；保留必要的限定、专业词、正式结构和读者需要的背景。
5. **反向检查**：确认 Humanizer 没有把判断改弱、把不确定性改成确定、把责任主体改丢，或把作者的差异磨成通用顺滑。
6. **署名决定**：作者确认可发布、需补来源、保留原句或不采用。没有作者确认时，交付应写成“完成编辑，人工终审待确认”，不写成最终定稿。

## 终审记录

推荐用短表记录，而不是写一篇新的分析：

| 项目 | 记录 |
| --- | --- |
| 事实已核对 | 数字、名称、链接和引用的状态 |
| 保留的作者判断 | 哪几处不能被“中性化” |
| 人工改动 | 读出声后实际删、并、改的句子 |
| 待确认项 | 来源、经历、政策适用范围或技术验证 |
| 发布状态 | 可发布 / 待补证据 / 保留原稿 / 不采用 |

## 反馈回写

把人工改动分成三类：

- **可复用规则**：同类场景至少重复两次，才考虑加入个人声音档案或场景规则。
- **单篇取舍**：只服务这篇稿子，留在 final-gate.md，不升级为全局禁词。
- **事实补充**：进入新的证据账本，不进入风格档案。

作者终审是“更像我”的主要证据来源。没有真实作者或人工盲评时，只能报告结构验证和静态检查，不能声称风格已经被证明。
