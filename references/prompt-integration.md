# 用户补充提示词的归并结果

## 保留为核心规则

- 风格自然、温暖、亲切，但温度来自具体材料、真实判断和节奏，不来自固定口头禅。
- 句子长短变化，段落有呼吸，朗读检查自然停顿。
- 使用简单清楚的词，优先具体动作、场景、数字和后果。
- 不写成学术腔、机械腔、营销腔或助手式问答。
- 写作前确认体裁、意图、读者、语气和材料来源。
- 先检测，再按意义膨胀、宣传腔、模糊归因、公式句、词汇和风格问题定点修改。
- 过度修改也会制造模板感，原稿已经自然时少动。

## 改为显式模式

- “适当加入嗯、其实吧、说实话、停顿和不完整句”只在温暖质感或风格学习模式启用。
- “加入小故事、生活例子和心理描写”只在材料提供或明确允许虚构时启用。
- “像朋友聊天”只适用于个人、社交、公众号和口播场景，不覆盖安全、党政、技术和正式报告。
- “高声说话”改为朗读检查，不默认使用夸张口语。

## 改为语境规则

- “赋能、生态、抓手、闭环、破局、颠覆式、底层逻辑”等列入复查表，不做无条件禁词。
- “不是 X 而是 Y”重点检查修辞动作，不因一次真实必要的对比就机械删除。
- “至少删 20%”改为低信息稿件的压缩目标；事实密集稿件不为比例硬删。
- 专业术语和英文词只在准确、必要或用户明确要求时保留，不为了显得简单而误改。

## 不采用为默认规则

- 不固定加入省略号、错误、粗口、网络梗或生活化细节。
- 不把“像真人”解释成刻意制造打字错误。
- 不把检测脚本的通过结果当成真人感、事实真实性或平台认可。
